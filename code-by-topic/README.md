# Code by topic

ตัวอย่างโค้ดที่จัดตามสไลด์ในโฟลเดอร์ `nu`

- `html/` — โครงสร้าง HTML5, semantic tags, ข้อความ/list/link/image, form และ table
- `css/` — font, pseudo-class, box model, display, flexbox, grid และ position
- `javascript/` — เงื่อนไข, loop, DOM/event, performance, array methods, Fetch API และ async/await

ไฟล์เดิมจากโฟลเดอร์ `nu` ถูกคัดลอกมาโดยไม่แก้ไขต้นฉบับ ส่วนไฟล์หมายเลข 08–10 ใน JavaScript และไฟล์ใน HTML/CSS ที่เพิ่มใหม่ เขียนขึ้นจากหัวข้อและตัวอย่างในสไลด์
